# Beecrowd 1065 - Pares entre Cinco Números

## Descrição

Este programa resolve o problema 1065 do Beecrowd, que consiste em ler 5 valores inteiros e contar quantos deles são pares.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe 5 valores inteiros quaisquer.

## Saída

O programa deve imprimir a quantidade de valores pares lidos, no formato:

5 valores pares
